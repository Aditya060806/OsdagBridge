A correction to the [comment of 20 Nov](https://github.com/Nidhikhare12/OsdagBridge/issues/20#issuecomment-7034132397), so that its fix and regression test can be applied as written. At `d74f56d` there is no `input_dict["steel_density"]`, `KEY_STEEL_DENSITY`, `KEY_SEC_MATERIAL` or `steel_prop.density`, and no Python code uses 76.93 kN/m³:

- The Material Properties dialog stores the density under `material.girder.density` ([`KEY_MATERIAL_GIRDER_DENSITY`, common.py#L73](https://github.com/Nidhikhare12/OsdagBridge/blob/d74f56dd7f22925fb8148cabf5740ed8d1e39ff3/src/osdagbridge/core/utils/common.py#L73)), in kN/m³.
- `SteelProperties` holds it as `rho`, in N/m³. All 28 grades in `Steel_Grade_Properties` store 78500, and a custom grade gets `_DEFAULT_DENSITY = 78500.0` ([plategirderbridge.py#L1192-L1194](https://github.com/Nidhikhare12/OsdagBridge/blob/d74f56dd7f22925fb8148cabf5740ed8d1e39ff3/src/osdagbridge/core/bridge_types/plate_girder/plategirderbridge.py#L1192-L1194)).
- `SteelProperties` is a frozen dataclass ([dto.py#L94-L95](https://github.com/Nidhikhare12/OsdagBridge/blob/d74f56dd7f22925fb8148cabf5740ed8d1e39ff3/src/osdagbridge/core/bridge_types/plate_girder/dto.py#L94-L95)), so overwriting a field after construction raises `FrozenInstanceError`. The custom value has to be passed when the object is built, as the fix in the issue description does.
- The girder self-weight load does not read `rho`. [analyser.py#L416](https://github.com/Nidhikhare12/OsdagBridge/blob/d74f56dd7f22925fb8148cabf5740ed8d1e39ff3/src/osdagbridge/core/bridge_types/plate_girder/analyser.py#L416) uses `STEEL_UNIT_WEIGHT_kN_m3 = 78.5` (see my comment above); `rho` only reaches the ospgrillage material definition ([L225](https://github.com/Nidhikhare12/OsdagBridge/blob/d74f56dd7f22925fb8148cabf5740ed8d1e39ff3/src/osdagbridge/core/bridge_types/plate_girder/analyser.py#L225)).

A regression test can therefore assert `bridge.material_props.steel_prop.rho == 85000.0` for an 85 kN/m³ input and check the self-weight line load. krithikmohan30's run above shows both staying at their defaults.
